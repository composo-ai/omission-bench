- **Leg A** - the per-fact check module inside the two-stage pipeline (B2 in the released data), with the extraction stage frozen and cached so the held-out run scores against the same fact lists the baseline was scored on. Decision: no prompt file was written: the rule set before the run was that a prompt is emitted only when the winner beats its baseline on the primary measure on held-out data.
- **Leg B** - the best monolithic judge: the criterion that checks whether the note is supported by the transcript and whether anything important is missing, answering with a 0-to-10 score (FC-score in the released data), seeded both with that criterion and with the hand-engineered omission prompt. Decision: the rule fixed before the run was to buy the held-out confirmation only if the winner beat the first seed on the acceptance set by more than 2 points on both measures. It did, by +7.3 points paired (0.688 against 0.615) and +22.9 points of detection (25.0% against 2.1%), and it cleared the second seed as well, whose acceptance figures are 0.646 paired and 18.8% detection, so the confirmation was bought.

- Leg A's acceptance-set gain was not distinguishable from noise on the acceptance set itself: of the 11 omission pairs the two prompts ordered differently, 8 went the winner's way and 3 the seed's, p = 0.23, and the consultation-clustered bootstrap runs from -4.2 to +16.2 points. The held-out set did not overturn a real effect; it declined to confirm a difference that the sample used to accept it could not resolve.
- On leg A's acceptance set both prompts flag the same 16 of 48 omission pairs, so the only thing that moved there is the false-alarm rate, 2 of 20 clean twins against 1 of 20.
- On the held-out set neither leg A prompt detects omissions at a rate distinguishable from its own false-alarm rate: z = 1.38 for the winner and z = 1.27 for the baseline.
- Leg B searched at one sample per note and confirmed at eight, so its acceptance rows and its held-out rows are the same criterion asked a different number of times; the comparison that carries the result is winner against baseline within each set, not across them.
- The tightest exclusion the two legs support is leg A's: its consultation-clustered bootstrap rules out a held-out gain above +2.7 points of paired discrimination. Leg B's own interval is wider, ruling out gains above +13.3 points.
- Leg A's held-out baseline was measured once, so there is no run-to-run spread for that architecture on these pairs. The yardstick row is leg B's monolithic baseline, whose three runs over the identical 131 omission pairs span 0.531 to 0.649 paired and 7.6% to 13.0% detection. That is 0.059 of paired movement either side of the midpoint from nothing but re-running the same judge, about 15 times leg B's held-out difference of +0.004.
- Paired discrimination on added or altered content is 0.950 for leg B's winner and 0.950 for its held-out baseline, so nothing the search did on omissions cost the judge anything on the errors it already sees.

**Caption.** **Two optimisation targets, what the acceptance set said about each and what the held-out set said.** Paired discrimination on omissions is the tie-adjusted share of pairs in which a judge scores the note with the omission below its own verified-clean twin, so 0.500 is a coin flip. Detection is read at the most sensitive threshold whose false-alarm rate stays within 10%, and is always quoted beside that false-alarm rate. The acceptance set is 20 consultations, 48 omission pairs and 20 clean twins, and the optimiser accepted or rejected candidates on it; the held-out set is 47 consultations, 131 omission pairs and 47 clean twins, split at consultation level because two pairs from one consultation share a transcript, a clean twin and a fact list, committed before any optimisation and scored once, at the end. Differences are in points of paired discrimination, so +0.004 reads as +0.4. Intervals are consultation-clustered bootstraps, sign tests count only the pairs the two prompts ordered differently, and the detection comparison is an exact McNemar test on the flag decisions. Leg B searched at one sample per note and confirmed at eight, so its two blocks are the same criterion asked a different number of times, and the comparison that carries the result is winner against seed within each block. Leg A's acceptance-set gain, the one the search was accepted on, is not distinguishable from noise on the acceptance set itself (8 wins to 3, p = 0.23). The last row is the yardstick: the same held-out baseline run three times, spanning 0.531 to 0.649 paired and 7.6% to 13.0% detection, which is about 15 times leg B's held-out difference of +0.004.
